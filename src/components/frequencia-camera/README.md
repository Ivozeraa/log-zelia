# Frequência por câmera

Módulo experimental para captura de vídeo e futura detecção/reconhecimento facial.

## Etapas

1. Captura da câmera.
2. Detecção facial com `@vladmandic/human`.
3. Cadastro de representações faciais.
4. Reconhecimento do aluno.
5. Registro de frequência no Supabase.

A implementação inicial não grava vídeo nem registra frequência automaticamente.
